## 📂 TECHNICAL DEEP DIVE (L'Anatomie du Code)

Pour les CTOs et les développeurs, voici ce qui tourne sous le capot :

### 🛠 Architecture & UX
* **Glassmorphism UI** : Utilisation de `backdrop-filter: blur(12px)` et de bordures translucides pour créer une hiérarchie visuelle sans alourdir la page.
* **Tailwind CSS (JIT)** : Moteur de style utilitaire pour une performance réseau maximale et une itération rapide.
* **Vanilla JS Logic** : Pas de frameworks lourds. Une manipulation DOM pure pour une réactivité immédiate (Zero-Latency).
